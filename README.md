# 번장 멀티챗

번개장터 여러 계정(최대 5개)을 계정마다 따로 로그인해서 한 화면에 나란히 띄우고, 새 채팅이 오면 소리와 팝업으로 알려 주는 Windows 프로그램입니다.

## 다운로드 (설치 없이 바로 실행)

**[BungaeMultiChat-portable.exe 받기](https://github.com/minsik2e5/bungae-multichat/releases/latest/download/BungaeMultiChat-portable.exe)**

- 받은 파일을 더블클릭하면 바로 켜집니다. 설치 과정은 없습니다.
- 처음 실행할 때 Windows가 "PC 보호" 경고를 띄우면 `추가 정보` → `실행`을 누르세요. (서명하지 않은 개인 제작 프로그램이라 나오는 경고입니다)
- 로그인 정보와 설정은 이 PC의 `%APPDATA%\BungaeMultiChat`에 저장되어, 새 버전 exe로 바꿔도 그대로 유지됩니다.

## 사용법

- **계정 추가** → 이름·색 정하기 → 생긴 창 안에서 카카오·네이버·본인인증으로 로그인. 한 번 로그인하면 껐다 켜도 유지됩니다
- 상단 **`번개톡 | 일반`**: 번개톡은 채팅 목록과 대화창만 크게, 일반은 번개장터 사이트 그대로 (모든 계정 공통)
- 상단 **`가- 100% 가+`**: 모든 창의 글자 크기를 한 번에 조절
- 상단 `가로`는 모든 계정을 한 줄로, `1~4`는 한 줄에 몇 개 띄울지
- **Ctrl+1~9**: 해당 계정 크게 보기 / **Ctrl+0**, **Esc**: 전체 보기

## 알림

- 새 채팅이 오면 **알림음**과 **화면 오른쪽 아래 팝업**(계정 색·이름, 보낸 사람, 메시지)으로 알립니다. 팝업을 누르면 그 계정 창이 크게 열립니다
- 대화방이 열려 있어도 울리고, 같은 방에서 여러 번 와도 메시지마다 울립니다. (광고) 채팅은 제외합니다
- Windows 기본 알림은 쓰지 않습니다 (번개장터 자체 알림도 이 팝업 하나로 합칩니다)
- 상단 `알림` 버튼: 알림음 종류·볼륨, 팝업 표시, 보고 있는 계정도 알릴지, `알림 테스트`
- 특정 계정만 끄려면 그 창의 `⋯ → 이 계정 알림 끄기`
- 앱을 켤 때 이미 쌓여 있던 메시지는 숫자만 보여 주고, 그 뒤에 오는 메시지부터 알립니다

## 매물헌터(Deal Hunter) 연결

- 멀티챗이 켜져 있으면 같은 PC에서 연 Deal Hunter의 상단과 왼쪽 메뉴 `번개톡` 페이지에 계정별 안 읽은 채팅이 표시되고, `열기`로 이 앱의 계정 창을 띄울 수 있습니다
- 연결은 이 PC 안(`127.0.0.1:47615`)에서만, Deal Hunter 주소에서 온 요청만 받습니다. 채팅 발송·로그인 정보 전달은 하지 않습니다
- 크롬이 처음 한 번 "로컬 네트워크 기기 접근" 허용을 물으면 허용하세요

## 알아둘 점

- 이 앱은 번개장터 사이트를 계정별로 분리된 창에 띄우는 것뿐입니다. 자동 답장·채팅 수집 같은 자동화 기능은 넣지 않았습니다
- 로그인 창에서 "허용되지 않은 브라우저" 류 메시지가 나오면 다른 로그인 방법(본인인증 등)을 써보세요
- 화면이 이상하면 그 창의 `⋯ → 채팅 화면 진단 정보 복사` 후 개발자에게 붙여 주세요

## 소스로 실행 / exe 만들기 (개발용)

1. https://nodejs.org 에서 LTS 설치
2. `START.bat` 더블클릭 (처음엔 설치 때문에 1~2분)
3. exe 만들기: `npm run dist` → `dist\BungaeMultiChat-portable.exe`
